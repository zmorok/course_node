# Интерфейс

React использует общий каркас с навигацией по роли и текущему разделу. Основные ссылки клиента — каталог, исполнители, свои проекты, заказы и уведомления. Отклики, приглашения, отзывы, жалобы, предупреждения, профиль и аккаунт находятся в раскрываемом меню «Ещё». У ADMIN доступна административная навигация. Скрытие ссылок не заменяет проверки backend.

`frontend/src/Ui.jsx` объединяет ошибки с перечнем замечаний, индикаторы статуса, пагинацию и загрузку удалённых данных. Общий loader скрывает данные прежнего URL при смене контекста. Ошибка загрузки содержит повтор; успешная команда и ошибка последующего обновления различаются. Пагинация сохраняет фильтры; страница вне диапазона предлагает вернуться в начало.

Режим заказчика/исполнителя выбирается в соответствующем списке и определяется сервером для карточки заказа. Статусы остаются предметными: одинаковое оформление не меняет допустимые переходы. Принятие предложения, отмена заказа, жалоба и меры администратора требуют явной формы подтверждения; ввод сохраняется при ошибке команды. Поданные жалобы и история решений доступны только для чтения.

Поддержаны видимый клавиатурный фокус, ссылка «К содержимому», подписи полей, aria-current/aria-pressed, объявления загрузки и ошибок, перенос длинных текстов и адаптация форм/карточек. Регистрационная форма сохраняет компактную двухколоночную раскладку на desktop. На небольшом экране поля и карточки становятся одноколоночными, меню раскрывается в потоке страницы.

Проверка этапа 19: React production build, 6 тестов API-клиента; браузерные переходы между списком и карточкой заказа, история результата/сроков/событий, жалобы, форма отзыва и отмена её редактирования, ошибка неверной страницы. При ширине 390 и 1280 px горизонтального переполнения в проверенных разделах нет. Полная проверка предметных сценариев выполняется `node scripts/test-infrastructure.mjs` в отдельной базе.
