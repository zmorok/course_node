# Интерфейс

React использует общий каркас с навигацией по роли и текущему разделу. Основные ссылки клиента — каталог, исполнители, свои проекты, заказы и уведомления. Отклики, приглашения, отзывы, жалобы, предупреждения, профиль и аккаунт находятся в раскрываемом меню «Ещё». У ADMIN доступна административная навигация. Скрытие ссылок не заменяет проверки backend.

`frontend/src/Ui.jsx` объединяет ошибки с перечнем замечаний, индикаторы статуса, пагинацию и загрузку удалённых данных. Общий loader скрывает данные прежнего URL при смене контекста. Ошибка загрузки содержит повтор; успешная команда и ошибка последующего обновления различаются. Пагинация сохраняет фильтры; страница вне диапазона предлагает вернуться в начало.

Режим заказчика/исполнителя выбирается в соответствующем списке и определяется сервером для карточки заказа. Статусы остаются предметными: одинаковое оформление не меняет допустимые переходы. Принятие предложения, отмена заказа, жалоба и меры администратора требуют явной формы подтверждения; ввод сохраняется при ошибке команды. Новая жалоба доступна автору для изменения и удаления до начала рассмотрения; рассматриваемые жалобы и история решений доступны только для чтения.

Поддержаны видимый клавиатурный фокус, ссылка «К содержимому», подписи полей, aria-current/aria-pressed, объявления загрузки и ошибок, перенос длинных текстов и адаптация форм/карточек. Регистрационная форма сохраняет компактную двухколоночную раскладку на desktop. На небольшом экране поля и карточки становятся одноколоночными, меню раскрывается в потоке страницы.

Проверка этапа 19: React production build, 8 frontend-тестов; браузерные переходы между списком и карточкой заказа, история результата/сроков/событий, жалобы, форма отзыва и отмена её редактирования, ошибка неверной страницы. При ширине 390 и 1280 px горизонтального переполнения в проверенных разделах нет. Полная проверка предметных сценариев выполняется `node scripts/test-infrastructure.mjs` в отдельной базе.

# Язык и тема — этап 26

В шапке всех страниц доступны RU/EN и светлая/тёмная тема. Предпочтения хранятся независимо в localStorage; язык и тема применяются сразу, без перезагрузки страницы. Переключение сохраняет введённые значения, ошибки формы, текущий URL и сессию. При недоступном хранилище настройки действуют до закрытия страницы. Переведены статические тексты клиентской и административной частей, подписи доступности, сообщения сервера и уведомления. Даты и числа используют выбранную локаль. Пользовательский текст и содержимое загруженных архивов не переводятся.

Словарь находится в `frontend/src/en.js`, подстановка параметров и выбор локали — в `i18n.js`, хранение предпочтений — в `preferences.js`. Цвета тёмного оформления заданы отдельной палитрой без изменения фотографий и других пользовательских медиа. Набор frontend-тестов проверяет непустые переводы, сохранение параметров сообщений и независимость языка/темы.

# Переходы без перезагрузки — этап 28

`Navigation.jsx` и `navigation.js` связывают React с History API браузера. Внутренние ссылки, фильтры, пагинация и переходы после команд меняют URL и содержимое раздела без нового HTML-документа. Шапка, настройки, сессия и таймер уведомлений сохраняются. При смене пути или query-параметров состояние страницы создаётся заново из URL: фильтры корректны после «Назад»/«Вперёд», карточки разных объектов не наследуют чужой черновик. Смена языка не пересоздаёт страницу и не повторяет загрузку данных.

Переход закрывает меню «Ещё», переносит фокус на основной раздел и прокручивает страницу к началу. Ссылки с Ctrl/Cmd, средней кнопкой, `target`, скачиванием, внешние адреса и якоря сохраняют стандартное поведение браузера. `/api` и `/assets` не считаются страницами приложения. Прямое открытие адреса и обновление вкладки обслуживаются существующим fallback на `index.html` в frontend-сервере.

Переводы справочных подписей вычисляются при отображении. Сообщения интерфейса в состоянии хранят ключ и параметры через `uiMessage`, серверные ошибки сохраняют исходный текст: уже показанные сообщения тоже меняют язык без нового запроса.
